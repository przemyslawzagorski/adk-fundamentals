## Jak wybrać gwiazdę nawigacyjną

### Półkula Północna
- **Zawsze szukaj Polaris** — jedyna gwiazda wskazująca niemal dokładnie biegun północny
- **Zima**: Sirius (najjaśniejsza!), Capella, Rigel, Betelgeuse
- **Wiosna**: Arcturus, Spica
- **Lato**: Vega, Altair, Deneb (Trójkąt Letni)
- **Jesień**: Fomalhaut

### Półkula Południowa
- **Brak odpowiednika Polaris** — używaj Krzyża Południowego (Acrux)
- **Metoda**: Przedłuż dłuższą oś Krzyża 4.5× — punkt wskazuje biegun południowy
- **Canopus**: Druga najjaśniejsza gwiazda na niebie, doskonała do pomiarów

## Trójkąt Letni (Lato, Półkula N)
```
        Deneb ★
       /       \
      /    △    \
     /           \
Vega ★ --------- ★ Altair
```
Widoczny od czerwca do października, łatwy do identyfikacji.

## Pas Oriona (Zima, obie półkule)
```
  Betelgeuse ★           ★ Bellatrix
              \         /
    Alnitak ★--★--★ Mintaka
            Alnilam
              /         \
       Saiph ★           ★ Rigel
```
Trzy gwiazdy Pasa wskazują na Sirius (w lewo-dół) i Aldebaran (w prawo-górę).

## Procedura obserwacji
1. **Zmierzch nautyczny** — najlepszy czas na obserwacje (horyzont widoczny + gwiazdy jasne)
2. Identyfikuj 3-4 gwiazdy rozłożone po horyzoncie (nie w jednym kierunku!)
3. Mierz szybko — max 4-5 minut między pomiarami
4. Zanotuj: gwiazda, kąt, czas, stan morza
